# Sistema de Reserva de Vagas de Estacionamento

## Sobre o projeto

O projeto consiste no desenvolvimento de um sistema web para gerenciamento de reservas de vagas de estacionamento em um condomínio residencial. A aplicação permite realizar o cadastro de reservas e consultar a situação das vagas, facilitando a visualização dos espaços disponíveis e ocupados.

O sistema foi desenvolvido como atividade acadêmica, utilizando tecnologias fundamentais do desenvolvimento web.

## Funcionalidades

- **Cadastro de reservas:** formulário para inserir informações do veículo, proprietário, apartamento e número da vaga.
- **Listagem de vagas:** visualização das vagas disponíveis e das vagas já reservadas.
- **Contabilização de vagas:** exibição automática da quantidade de vagas disponíveis e reservadas por meio de JavaScript.
- **Navegação entre telas:** botões que permitem alternar entre a tela de cadastro e a tela de listagem.

## Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização e organização dos elementos visuais.
- **JavaScript:** validação e manipulação dos elementos da página, além da contabilização das vagas.

## Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Acesse a pasta `html`.
4. Abra o arquivo `cadastrar_reserva.html` em um navegador.
5. Utilize os botões disponíveis para navegar entre as telas.

Não é necessária a instalação de dependências ou configuração de servidor para executar o projeto.

## Observações

O projeto possui caráter demonstrativo e utiliza dados fictícios na tela de listagem. Não há integração com banco de dados ou armazenamento permanente das reservas.
